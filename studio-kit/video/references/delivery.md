# Delivery

Retain the raw silent capture, final silent picture, timed narration Markdown, cues, markers, results, raw narration, normalized WAV, narrated MP4 and WebM, chapter stills, full-timeline contact sheet and manifest. Probe final duration (30–45 seconds), resolution, codecs, audio presence, frame rate and sample rate. Measure final loudness and peak after encoding.

Use a manifest containing file size, SHA-256, model revision, voice, ffprobe output and QC limitations. Inspect representative frames and the full timeline; listen to the whole final file when possible. State when a human listening pass or ASR did not occur. Distinguish an in-memory confirmation from persistent production data.

Keep media, local tools and model downloads ignored. Provide one reproduction command and setup requirements. Approval and delivery of a video belong to the upstream version/hash gate; producing a file does not authorize sending it to a client.
