# Capture and picture checks

Use headless Chromium, one worker, native Playwright video, and matching 1920×1080 viewport/recording dimensions. Set up data before capture. Abort requests to any origin outside the approved loopback application; do not silently load analytics or external assets.

Prefer exact accessible names. Wait for successful responses and visible UI before adding pacing pauses. Record timestamps at the action's observable outcome. Use invented names and example.test email addresses. End the success state with at least four seconds of stable picture.

Trim only harmless initial blank frames, shifting narration markers consistently. The sample uses a 0.2 second trim; allow for capture startup uncertainty when checking sync. Inspect the opening, form, entered values, confirmation and closing frames. Scan a contact sheet of the entire timeline. Check phone-width receipt layout separately. No synthetic cursor is required; do not introduce a cursor animation that could obscure controls.
